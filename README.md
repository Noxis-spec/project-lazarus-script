<h1 align="center">Grondex Hub</h1>
<p align="center">All-in-one script for Project Lazarus: ZOMBIES</p>

---

## Features

- **Instant Kill** — zombies die from a single bullet
- **Infinite Ammo + No Reload** — magazine is always full, reload never starts
- **No Recoil** — camera stays stable while shooting
- **FOV Changer** — adjustable field of view
- **Rainbow Gun** — weapon changes colors
- **Zombie ESP** — red outline around zombies
- **Mystery Box ESP** — white outline around the Mystery Box
- **Pack-a-Punch ESP** — blue outline around the Pack-a-Punch
- **Speed** — move faster than normal
- **Noclip** — walk through walls
